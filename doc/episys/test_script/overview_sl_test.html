Overview & Key Features

What It Tests

  • Mode 2 PC5 direct D2D communication
  • Mode 1 Network-scheduled sidelink
  • SRAP U2N relay for remote UE connectivity
  • CSI / PSFCH Parametric feedback testing
  • Uu gNB ↔ UE interface testing

Key Features

  • Array-based test selection — simple ordered list
  • Parametric sweeps — CSI × PSFCH combinations
  • Multi-host support — 1, 2, or 3 machines via SSH
  • Profile-based config — pilot / regress / stress
  • Auto result tracking — ping + PSSCH statistics
Two scripts: run_sl_test.sh (test engine) + run_sl_test_config.sh (user configuration)

Architecture & Execution Flow

Execution Flow

1. Load config (run_sl_test_config.sh) 2. Resolve enabled_tests array 3. For each test: a. Clean up old logs b. Launch UEs (local / remote SSH) c. Wait for tunnel interface d. Execute ping test e. Collect stats (ping + PSSCH) f. Kill processes & cleanup g. Generate summary row 4. Display final summary table

File Structure

run_sl_test.sh # Test engine run_sl_test_config.sh # Configuration ~/.ssh/config # SSH host aliases ~/openairinterface5g/ # OAI source <script_dir>/ latest -> test_<ts>/ # Symlink test_<timestamp>/ # Results test_summary_*.csv result_syncref.log result_nearby.log ping_result_*.txt

Multi-Host Testing

Test Topologies

Single-Host (Mode 2): SyncRef UE <--rfsim--> Nearby UE (both on localhost) Two-Host (Mode 2): Local: SyncRef UE (rfsim server) Remote: Nearby UE (rfsim client) Three-Host (Mode 1 SRAP): gNB host: gNB + 5G Core relay_ue host: Relay UE (Uu + PC5) remote_ue host: Remote UE (PC5)

PSSCH Rate Calculation

  • Rate1: SyncRef TX → Nearby RX
    RX_nearby / TX_syncref
  • Rate2: Nearby TX → SyncRef RX
    RX_syncref / TX_nearby
  • Total: Aggregated both directions
    (RX_sync + RX_nearby) / (TX_sync + TX_nearby)
